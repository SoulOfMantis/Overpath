## Basics 
- Robot's rush destroys both the hero and other robots in it's path!
- Interact with the terminal to gain access to corresponding robot's program
- Interact with the door to complete the level

### Controls
- WASD to walk
- Space to skip the turn
- F to interact with the object in front of the player

### Using the terminals
- When you enter a number into the field, it will turn red. Press Enter to confirm and the number will turn black.
- Choose one of list's options to apply it
- Press an arrow in the right part of the code panel to swap it with the one below/above
- Terminal's right upper corner contains counter of applied changes and the maximum available. If the numbers are equal, you cannot apply new changes to this terminal.
- If you try to apply changes after reaching maximum number, the terminal will "crash" without applying them. It can still be opened again to check the program.

### Buttons
- While the button is pressed by a robot or a player it activates or deactives the connected barrier!
- If the barrier activates while it's occupied by a player or a robot, this character will be destroyed!
